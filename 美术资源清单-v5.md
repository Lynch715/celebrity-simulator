# 《模拟明星》美术资源清单 v5

> 用途：交给 GPT 出图。出完按本文的**文件名**放进 `模拟明星/art/` 对应子目录，游戏自动生效，不需要改代码。
> 图标（46 个）已经在 `模拟明星.html` 里用原创 SVG 画好了，**不需要 GPT 出**——见第五节。GPT 只需要出**位图 46 张**（立绘 32 + 场景 14）。

## 一、接入方式

### 1.1 目录结构

```
模拟明星/
├─ 模拟明星.html
└─ art/
   ├─ npc/     20 张 NPC 半身立绘
   ├─ hero/    12 张 主角出道形象
   └─ scene/   14 张 场景大图
```

### 1.2 代码里已经做好的事

`模拟明星.html` 新增了 `ART` 资源表，取图顺序是：

1. `ART_DATA[key]` —— 内嵌 base64（想保持真·单文件时用）
2. `art/<子目录>/<文件名>` —— 文件夹模式（**推荐，改图不用动 HTML**）
3. 都没有 → 回落到内置的原创 SVG 占位（不会报错、不会破版）

切换方式在 `<script>` 开头：

```js
const ART_BASE = "art/";   // 想内嵌就设成 ""，然后往 ART_DATA 里填 base64
```

图片加载失败会静默回落到 SVG 占位，所以**可以一张一张往里补**，补一张生效一张。

### 1.3 通用技术规格

| 项 | 要求 |
|---|---|
| 格式 | `.webp`（质量 82-88）。GPT 出的是 PNG，用 `cwebp -q 85 in.png -o out.webp` 转 |
| 立绘背景 | **纯透明**（PNG 带 alpha 再转 WebP）。不要白底、不要渐变底 |
| 场景图背景 | 不透明，允许四周压暗 |
| 色彩 | 见 1.4 风格锚点。**不要偏亮、不要偏饱和**，游戏底色是 `#151515` |
| 文字 | 图里**一个字都不要有**（水印、logo、字幕全不要） |
| 单张体积 | 立绘 ≤ 120KB，场景 ≤ 260KB |

### 1.4 风格锚点（所有图必须一致）

已有的两张主视觉定了调子：**电影感写实、低照度、暖金主光 + 冷蓝轮廓光、红毯与片场器材作点缀、浅景深、细颗粒**。所有新图都必须能和它们放在同一屏里不打架。

**统一风格前缀（每条提示词前面都粘这一段）：**

```
Cinematic photorealistic still, contemporary Chinese entertainment industry.
Low-key lighting, deep shadows, warm gold key light (#d7b35a) from one side,
cool blue rim light (#67aaa8) from the other. Muted desaturated palette on a
near-black background (#151515). Shallow depth of field, 85mm lens look,
subtle film grain, no HDR glow. East Asian cast, natural realistic faces,
age 25-45 unless stated. No text, no watermark, no logo, no subtitles.
```

**统一反向提示词：**

```
Negative: text, watermark, logo, signature, subtitles, cartoon, anime, 3d render,
cgi, plastic skin, oversaturated, bright daylight, white background, HDR,
extra fingers, deformed hands, blurry face, beauty filter, western faces.
```

## 五、图标系统（已完成，无需 GPT 出图）

`模拟明星.html` 里已经写好了 **46 个原创单色 SVG 图标**，全部 24×24 viewBox、`stroke: currentColor`、线宽 1.6、圆角端点，跟着 CSS 变量走主题色。原来的字符图标（`▣ ◎ ♟ ▲ ◇ ! ♥ ⚔ ♫ ◆ ↻ ★ ✦`）和唯一一个 emoji（`🔒`）已全部替换。

调用方式：`ico("clapper")` 返回 SVG 字符串。

| 分组 | key | 用在哪 |
|---|---|---|
| **行动（8）** | `clapper` `network` `people` `target` `moon` `megaphone` `lightstick` `swords` | 首页 8 个行动格 |
| **项目类型（8）** | `film` `tv` `confetti` `note` `mic` `bag` `signal` `hands` | 项目卡类型标 |
| **风险（8）** | `contract` `receipt` `pulse` `mind` `lens` `chain` `crowd` `mask` | 风险征兆 / 伏笔弹窗 |
| **擂台战术（5）** | `target` `network` `hash` `coin` `yield` | 擂台三局选项 |
| **技能（5）** | `mask` `mic` `sparkle` `hanger` `bubble` | 专业能力五宫格 |
| **团队岗位（6）** | `briefcase` `calendar` `backpack` `megaphone` `scissors` `whistle` | 团队卡岗位标 |
| **人设（6）** | `book` `heart` `sun` `snow` `bolt` `flame` | 人设徽章 |
| **UI（8）** | `reset` `lock` `star` `diamond` `check` `warn` `dot` `dotOff` | 重开、未解锁、成就、专精、行动力点 |

**如果你仍然想让 GPT 出图标**（比如想要金属浮雕质感的），要求是：512×512 PNG 透明底、单色描边、无投影、无渐变、线宽视觉上一致，命名 `art/icon/<key>.webp`，代码会自动优先用位图。但**不建议**——25px 的位图图标在暗色 UI 上会糊，矢量更锐利。
